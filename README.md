# 校园网登录器（电脑版）

韩山师范学院校园网自动登录工具。单文件 exe，开机/联网自动认证，账号密码用 Windows DPAPI 加密保存在本机注册表——不落盘、不上传、换电脑解不开。

## 功能

- **一键登录**：保存账号密码后，点一下即可完成校园网认证
- **自动登录**：开机（延迟 5 秒）、断网重连、睡眠/休眠唤醒、锁屏解锁时自动静默登录，所有结果均弹系统通知，失败后每分钟自动重试（最多 3 次）
- **凭证保密**：账号密码经 DPAPI 加密（绑定本机当前 Windows 用户）存于注册表，磁盘上不产生任何凭证文件
- **免管理员**：自启动通过任务计划实现，普通权限即可设置
- **高分屏适配**：125% / 150% 缩放比例下界面文字清晰不模糊
- **赞赏与反馈**：界面底部内置赞赏码，遇到问题可打赏备注反馈或到 [GitHub Issues](../../issues) 提交
- **小而精**：登录完成即退出，不常驻后台

## 下载使用

从 [Releases](../../releases) 下载 `HSTC-CampusLogin.exe`（即校园网登录器，GitHub 附件不支持中文文件名），双击运行：

1. 输入校园网账号（12 位数字）和密码，点击「保存凭证」
2. 点击「设置自启动」，之后开机/联网即自动登录
3. 也可以直接点「立即登录」手动认证

> exe 为单文件绿色软件，可放任意目录；换电脑使用时需重新输入一次账号密码（凭证绑定本机的安全设计）。

## 从源码运行

```bash
pip install -r requirements.txt

python main.py            # 图形界面
python main.py --silent   # 静默登录（无界面，成功/已在线/非校园网退出码 0，失败 1）
```

要求 Python 3.9+、Windows 10/11。

## 打包 exe

```bash
pyinstaller --onefile --windowed --name 校园网登录器 --add-data "赞赏码.jpg;." main.py
```

打包产物在 `dist\校园网登录器.exe`，单独复制到任意文件夹即可使用。

## 工作原理（登录实现方法）

登录核心为 `login_core.py`，模拟浏览器完成韩师 CAS 统一认证，全流程如下：

### 1. 校园网环境检测

访问校内地址 `rz.hstc.edu.cn`，3 秒内可达即视为在校园网内；不在校园网则直接退出，不做无谓请求。静默模式下刚唤醒或刚联网时网络可能还没就绪，会在 30 秒内每隔几秒重试检测，仍不可达才判定为不在校园网。

### 2. 采集本机网络信息

- **本机内网 IP**：UDP 连接法获取（向 8.8.8.8 发起连接但不真正发包）
- **MAC 地址**：`uuid.getnode()` 取 12 位小写
- **默认网关**：解析 `route print` 路由表（兼容中英文系统的「在链路上 / On-link」字样）
- **接入点名称**：按网关查表映射（如 `192.168.2.33 → CORE-RG-N18012`）

### 3. 构造 CAS 登录地址

把 `IP|MAC|网关|接入点` 拼成 state 串并 Base64 编码，附在门户地址后作为 `service` 参数，得到完整的 CAS 登录地址（`hscas.hstc.edu.cn/cas/login?service=...`）。

### 4. 提交认证表单

1. GET 登录页，正则提取隐藏域中的 `execution` 标识（会话一次性令牌）
2. GET `/cas/jwt/publicKey` 获取 CAS 公钥，密码用 **RSA（PKCS1_v1_5）加密** 后 Base64 编码，加 `__RSA__` 前缀（与服务器约定一致），明文密码不出本机内存
3. POST 提交表单（username / password / execution 等）

### 5. 按返回页标题判定结果

| 返回页标题 | 判定 |
|---|---|
| 认证成功页 | 登录成功 |
| 信息页 | 已在线，无需重复登录 |
| HTTP 401 | 账号或密码错误 |
| 其他 | 认证异常 |

所有请求均带超时，不会无限卡死；结果通过系统通知告知，失败时任务计划自动重试。

### 凭证安全

账号密码经 **Windows DPAPI** 加密（绑定本机当前 Windows 用户 + 附加熵）后存于注册表 `HKCU\Software\校园网登录器`，磁盘上不产生任何凭证文件；换电脑或换用户均无法解密，需重新输入。

自动登录通过 Windows 任务计划实现：当前用户登录触发（延迟 5 秒等网络就绪）+ 网络连接变化触发 + 睡眠/休眠恢复触发（延迟 5 秒）+ 锁屏解锁触发（延迟 5 秒），均为普通权限，不占用后台；登录失败时任务计划每分钟自动重试（最多 3 次）。

## 目录说明

| 文件 | 说明 |
|---|---|
| main.py | 入口：双击开 GUI，`--silent` 静默登录 |
| gui.py | CustomTkinter 图形界面 |
| login_core.py | CAS 认证流程 |
| credential_storage.py | DPAPI 加密 + 注册表存取（含旧版凭证自动迁移） |
| autostart_manager.py | 任务计划的注册/查询/取消 |
| notifier.py | Windows 通知（登录成功/失败提醒） |
| 赞赏码.jpg | 随 exe 打包的赞赏码图片（界面底部展示） |
